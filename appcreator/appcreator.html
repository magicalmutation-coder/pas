Add an app from elsewhere

Build it anywhere, then install it here. An app package is a folder with module.json and <name>.html (plus an optional <name>.psm1 for server routes and tools). Hand the spec to another agent and it can build one for you.

import asks for a path (a folder or a .zip) and copies it into modules\<name>\; nothing needs a restart. start a package writes a starter folder to workspace\apps-build\<name>\ - edit it with the agent (it can write the workspace), then import it. To move an app the other way, right-click it in Apps and choose Export as a package; that writes dist\<name>-app.zip. Only import packages you trust: a page runs in this dashboard and a .psm1 runs with your rights.
