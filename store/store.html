Publish an installed app

Copies modules\<app>\ into the store, updates its index.json, and when the store is a git clone with a remote commits and pushes it. Set the app's category and description in its module.json (Apps > right-click > Move to a category).

Add a store

A store is a folder with app packages (module.json + <name>.html) and an index.json catalogue. A local store needs no git; a url makes pull fetch and publish push. Only install apps you trust - a page runs in this dashboard and a .psm1 runs with your rights.
